# Social Statistics

## What is this?
Social Statistics is a responsive multi-page website about the effects of social media and healthier digital habits. It includes a homepage, pages about social media impact and habits, a daily habit tracker, and a facts page that explains the purpose of the project.

## Why does it exist?
This project exists to help people think more carefully about how they use social media. The goal is to show both the benefits and the drawbacks of social platforms and give users simple ways to build better online habits.

## What tools did I use?
I used HTML, CSS, and JavaScript to build the site. HTML was used for the page structure, CSS for layout and visual design, and JavaScript for the theme toggle and habit tracker. I also used GitHub Pages to deploy the site so it could be viewed online.

## What changed from Project 01 to Project 02?
Project 01 was a single-page website with section links inside one page. For Project 02, I expanded the site into multiple pages so each tab opens a different page with its own content. I also improved the layout, kept the theme toggle, added a more organized navigation system, and included a working habit tracker to make the site more interactive and useful.
